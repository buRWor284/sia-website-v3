How we handle the data

so nothing in this tool is invented
1
Every number is sourced.

Each figure is either quoted from the report or calculated from quoted figures by a stated formula. Nothing is untagged.

2
Gaps stay gaps.

Where the report has no data for a specialty, we show "not separately reported," never a made-up number.

3
Provenance is on screen.

A tag sits next to every figure (hover it for the source page), so you can see at a glance what is reported vs estimated.

4
Reviewed before release.

Every value is checked against the source report before publishing: reported, derived, or estimated.
